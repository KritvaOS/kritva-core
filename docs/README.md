# Kritva Core Documentation

This directory contains maintained architecture, public API, security, and development documentation for Kritva Core.

## Canonical documentation layers

- `architecture/` — architectural principles, boundaries, and design decisions.
- `api/` — human-readable public API contracts. Markdown is authoritative.
- `compatibility/` — the Core 1.x compatibility and evolution contract (public API inventory, source and semantic compatibility, ABI posture, versioning, deprecation) with its audits.
- `security/` — security architecture, trust boundaries, and threat-model records.
- `development/` — development and contributor guidance.
- `architecture/archive/` — historical review records retained for traceability.

## Authority

The accepted public API contract is defined by the reviewed repository headers and the corresponding maintained documentation under `api/`.

Planning records under `../planning/` govern milestone execution and acceptance; they are not a substitute for the maintained API documentation.

Generated HTML/PDF documentation, if introduced later, is publication output and not the authoritative source.
