# Kritva Core Deprecation Register

The register of deprecated stable items, maintained under `DEPRECATION_POLICY.md`. Every deprecated item appears exactly once; an item leaves the register when it is removed in a MAJOR release.

**At 1.0.0 no stable item is deprecated.** The register is empty by design: no deprecation is introduced to demonstrate the policy.
