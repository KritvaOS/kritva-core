# KF-CORE-R10-004 — Versioning & API Evolution Policy

## Objective

Define SemVer release-impact classification and change-review rules for public API, semantics, package behavior and compatibility-sensitive values.

## Dependencies

R10-003.

## Scope

Perform only the approved R1.0 compatibility/evolution work for this task. Preserve R0.9 functional semantics unless an explicit compatibility decision authorizes a narrowly scoped change.

## Exclusions

Do not introduce new platform-specific or unrelated runtime functionality.
